# CRUD de Funcionários (Java)

Sistema de gestão de funcionários em console, desenvolvido em Java, que permite **criar, exibir, atualizar e remover** registros.

## Funcionalidades
- Cadastro de funcionários (nome, matrícula, admissão, demissão, salário e horário)
- Busca e exibição por matrícula
- Atualização dos dados de um funcionário
- Exclusão por matrícula
- Menu interativo em loop: (C)riar, (E)xibir, (R)emover, (A)tualizar e (S)air

## Conceitos aplicados
- Programação orientada a objetos (classes `Funcionario` e `GestaoFuncionarios`)
- Matriz de objetos com 50 posições
- Manipulação de datas com `LocalDate`
- Entrada de dados com `Scanner`

## Como executar
1. Clone o repositório ou baixe os arquivos
2. Abra em uma IDE Java (IntelliJ, Eclipse ou VS Code)
3. Execute a classe que contém o método `main`
